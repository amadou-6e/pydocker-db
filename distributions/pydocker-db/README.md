# pydocker-db

Install database container helpers with `pip install pydocker-db`.

This distribution depends on `py-dockerdb`, which remains the sole owner of the
`docker_db` Python package. Existing `pip install py-dockerdb` and `docker_db`
imports continue to work. This distribution installs no Python modules, so an
upgrade cannot remove another distribution's import files.

Source and support: https://github.com/amadou-6e/pydocker-db
